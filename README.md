# hamidzr.github.io

Static GitHub Pages site, no build step.

- `index.html`: landing page with resource links
- `referrals.html`: referral links (`referral.html` is a symlink to it)
- `player.html`: asciinema cast player (SRI-pinned CDN assets)
- `dl/`: downloadable files, served under `/dl`
- `assets/`: shared static assets
